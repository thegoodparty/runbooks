# Script Index

Quick reference for all available scripts. Keep this updated when adding or removing scripts.

| Script | Description | Used By |
|--------|-------------|---------|
| `python/databricks_query.py` | Execute SQL queries against Databricks and return results as a DataFrame | books/query-voter-data.md |
| `python/circle_query.py` | GET wrapper for the Circle Admin API v2 (Bearer auth). CLI prints JSON; `get()` helper for programmatic use | books/connect-circle-api.md |
| `python/circle_engagement.py` | Full engagement snapshot — DAU/WAU/MAU, stickiness, contribution mix, content rate, top spaces/contributors, cohort retention | books/circle-engagement-snapshot.md |
| `python/clickup_api.py` | ClickUp API wrapper (GET/POST/PUT/DELETE) with token auth; v2 by default, `--api-version=v3` for the Docs/Pages API. CLI prints JSON; `get/post/put/delete()` helpers for programmatic use | commands/clickup-epic-create.md, commands/clickup-epic-edit.md, commands/work-on-clickup.md, commands/prd-to-tech-design.md |
| `python/qa_validate.py` | Validate a qa-spine-compliant artifact JSON: deterministic checks + Phase 1 LLM triage + Phase 2 adversarial escalation → release_verdict (ok/warn/block) + per-claim verdicts in qa_bundle.json. Product-agnostic; product-specific rules live in a `<product>_product_spec.json`. | books/qa-validate.md |
| `python/eval_trajectory.py` | Trajectory eval — score an agent run's execution trace (`conversation.jsonl`, both Fargate + local dialects): turns, cost, tool_errors, exact-duplicate calls, planning overhead %, optional command-regex category breakdown. `--ab control_dir treatment_dir` diffs two prompt versions with an outcome-parity check. | books/evaluate-experiment-runs.md |
| `python/meeting_briefing_eval_rules.json` | Example `--rules` file for `eval_trajectory.py` — command-regex → category labels (schema_read, qa, http_fetch, databricks, pdf_extract, artifact_build) for the meeting_briefing experiment. | books/evaluate-experiment-runs.md |
| `python/rubric_verdict.py` | Tally cold-judge rubric scores (TSV: `uuid	batch	judgeA	judgeB`, `DQ` for disqualified) into a GO/NO-GO **reliability** verdict — graded inter-judge spread, gate-decision reproducibility, blowout count. Reliability only, not validity. Example data: `experiment-evals/meeting_briefing/rubric_scores.tsv`. | books/evaluate-experiment-runs.md |
| `python/faithfulness_check.py` | Offline external-faithfulness check (candidate Gate B3): extract identity figures (money, percent, legal cite, date) from each claim and string-match them against the cited source text. Default checks the artifact's embedded snapshot (catches naive fabrication); pass a resolver to check the runner-persisted raw download instead (gaming-resistant — catches a fabrication faked consistently across claim, extract, and snapshot). Reference implementation shaped to the meeting_briefing contract; adapt field names per experiment. | books/build-output-quality-rubric.md |
| `shell/coldrun-build-rubric.sh` | Fair-test loop: for each experiment, launch a context-free `claude -p` headless session that builds a quality rubric by following `books/build-output-quality-rubric.md` alone (barred from reading existing rubrics), writes to `$OUTROOT/<exp>/`, waits on all. Doubles as runbook validation — where a cold agent struggles is where the runbook is underspecified. Caller supplies `CLAUDE_CONFIG_DIR`/`AWS_PROFILE`. | books/build-output-quality-rubric.md |
| `python/verify_urls.py` | Verify a list of URLs return HTTP 200 (HEAD first, fallback to GET on 403/405/501). Follows redirects, returns `{url, status, final_url, ok, error?}` per row as JSON. Reads URLs from argv or stdin. | Standalone local/dev URL vetting only. NOT invoked by any experiment at runtime — agents verify URLs with `pmf_runtime.http.head` inside the sandbox (direct HTTP / this script would hang in the quarantined network). |
| `shell/generate-roadmap-pdf.sh` | Convert an EO's roadmap markdown variants to clean PDFs (pandoc + headless Chrome) | books/generate-governing-roadmap.md |
